# Google Sans

Source: https://github.com/google/fonts/tree/main/ofl/googlesans

Downloaded 9 October 2026. Original variable TrueType file, OFL license, and upstream metadata are included unchanged. The variable font supports weights 400–700, optical size 17–18, and grade -50–200. Upstream metadata declares Khmer and Latin support.

The Codex component preview loads this file locally. Its Khmer sample was checked against the font cmap, and browser font inspection confirms Google Sans renders the Khmer specimen. This does not establish that Google Sans is installed in the external Figma or Canva environments.

Admin uses a derived subset with Latin, Khmer, punctuation and currency symbols, retaining all shaping features and variable axes. The original font and OFL license remain here.
