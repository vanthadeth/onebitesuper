# OneBite mascot concepts

Ten proposed character designs, built as native vector SVG. Uses the earlier single-tooth concept. Every asset loops automatically with a gentle character-specific motion. CSS animation works inline and through an image element; no JavaScript is required. Reduced-motion preferences disable animation. Individual assets have transparent backgrounds, a 320 × 320 viewBox, accessible titles/descriptions, and no embedded raster images, external resources, scripts or font dependencies. They are new illustrations inspired by OneBite; the supplied approved logo files are preserved separately.

Run `node scripts/mascot-concepts.mjs` to regenerate the vectors and comparison sheet.

| Design | Suggested use |
| --- | --- |

| [Cashier Bite](02-cashier-bite.svg) | POS ordering and shared-terminal welcome |
| [Chef Bite](03-chef-bite.svg) | Recipes and cooking instructions |
| [Stock Bite](04-stock-bite.svg) | Inventory receiving and stock messages |
| [Time Bite](05-time-bite.svg) | Attendance and shift reminders |
| [Guardian Bite](06-guardian-bite.svg) | Admin permissions and secure confirmations |
| [Happy Bite](07-happy-bite.svg) | Successful saves and completed orders |
| [Thinking Bite](08-thinking-bite.svg) | Help, recipe tips and useful prompts |
| [Sleepy Bite](09-sleepy-bite.svg) | Manually locked terminal or overnight custody |

Default recommendation: Hello Bite as the general character; role-specific variants can extend it across POS, Inventory, Attendance and Admin. No mascot has been applied to the live apps yet. The comparison sheet has an opaque canvas; each individual mascot remains transparent.
