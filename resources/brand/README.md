# OneBite brand resources

All 10 supplied SVG files are preserved byte-for-byte with their original filenames. They are vector artwork with outlined lettering; the logo wordmark must not be retyped in Google Sans.

## Asset selection

- `one-bite-logo-{orange,black,white}.svg`: complete horizontal logo, aspect ratio 325:144. Use for sign-in and introductory brand placements.
- `one-bite-icon-{orange,black,white}.svg`: mascot icon, aspect ratio 152:144. Use for compact branding and the source for future PWA icons.
- `one-bite-wordmark-{orange,black,white}.svg`: stacked wordmark, aspect ratio 147:124. Use where the mascot is already visible.
- `one-bite-logo-kit.svg`: supplied reference sheet, not a replacement for an individual production asset.

Use orange or black on light surfaces, and white on dark surfaces. Preserve proportions, fills, paths, and the mascot's expression. Do not crop, stretch, add shadows, rotate, or recolor the approved artwork. Preserve SVG transparency. PWA exports later need suitable opaque backgrounds and maskable safe areas, not a stretched source.

See [brand-guidelines.md](brand-guidelines.md) for proposed usage rules, [brand-tokens.json](brand-tokens.json) for exact colors and typography, and `asset-manifest.json` for original file hashes.

`onebite-brand-guidelines.svg` is a locally prepared board for manual Figma import and review. It has not been added to the Figma file. The selected team's MCP tool-call limit still blocks Figma editing. Google Sans is requested for both English and Khmer; its actual available Figma styles and script rendering remain to be verified.
